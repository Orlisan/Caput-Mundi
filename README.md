# CAPUT MUNDI

"Roma in Italia est.
Italia in Europa est.
In Arabia pauci fluvii et pauca oppida sunt.
Marcus eam pulsat.
Aemilia, quae mater Marci est, Marcum verberat, quia Marcus puer improbus est.
Quem Iulius non audit? Quintum Iulius non audit. Cur Iulius eum non audit? Quia Iulius dormit
Iam Iulius non dormit, sed venit.
In sacculo eius non centum, sed decem nummi sunt"
